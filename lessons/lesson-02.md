# บทเรียนที่ 2: เงื่อนไข (if) และลูป (for)

> **เป้าหมายบทนี้:** ให้โปรแกรม "ตัดสินใจ" ได้ด้วย `if` / `elif` / `else` และ "ทำงานซ้ำ" ได้ด้วย `for` กับ `range()`
> โค้ดทุกตัวอย่างในบทนี้ **รันผ่านทดสอบมาแล้ว** — รันเองเทียบผลได้เลย

## 1. ให้โปรแกรมตัดสินใจ: if / else

โจทย์: เช็คว่ายอดขายถึงเป้าหรือไม่

โค้ดอยู่ที่ไฟล์ `lesson2_if.py`:

```python
sales = 150
target = 100

if sales >= target:
    print("ผ่านเป้า 🎉")
else:
    print("ยังไม่ถึงเป้า")
```

**อธิบายทีละส่วน:**

- `if เงื่อนไข:` — ถ้าเงื่อนไข**เป็นจริง** ให้ทำบรรทัดที่**เยื้องเข้าไป**ข้างใต้
- หลัง `if` ต้องมี **โคลอน `:`** เสมอ (จุดที่มือใหม่ลืมบ่อยที่สุด!)
- **การเยื้อง (indent) 4 เคาะ** = บอกว่า "บรรทัดนี้เป็นส่วนของ if" — Python บังคับเรื่องนี้จริงๆ ไม่ใช่จัดให้สวย
- `else:` — ถ้าเงื่อนไข**ไม่จริง** ให้ทำส่วนนี้แทน
- เครื่องหมายเปรียบเทียบที่ใช้บ่อย:

| เครื่องหมาย | ความหมาย |
|---|---|
| `>` | มากกว่า |
| `>=` | มากกว่าหรือเท่ากับ |
| `<` | น้อยกว่า |
| `<=` | น้อยกว่าหรือเท่ากับ |
| `==` | **เท่ากับ** (ต้อง 2 ตัว! `=` ตัวเดียวคือการใส่ค่า) |
| `!=` | ไม่เท่ากับ |

### 🔮 ทายก่อนรัน

1. รันแล้วจะเห็นอะไร?
2. ถ้าแก้ `sales = 80` จะเห็นอะไรแทน?

### ✅ เฉลย

<details>
<summary>กดดูเฉลย</summary>

```
ผ่านเป้า 🎉
```

เพราะ 150 >= 100 เป็นจริง

ถ้า `sales = 80` → พิมพ์ `ยังไม่ถึงเป้า` (80 >= 100 เป็นเท็จ)

</details>

## 2. หลายเงื่อนไข: elif

โจทย์: คิดส่วนลดตามยอดซื้อ — ตั้งแต่ 2000 ลด 10%, ตั้งแต่ 1000 ลด 5%, ต่ำกว่านั้นไม่ลด

โค้ดอยู่ที่ไฟล์ `lesson2_discount.py`:

```python
total = 2500

if total >= 2000:
    discount = 0.10
elif total >= 1000:
    discount = 0.05
else:
    discount = 0

print("ได้ส่วนลด", discount * 100, "%")
print("จ่ายจริง", total * (1 - discount))
```

**อธิบาย:**

- `elif` = "ไม่งั้นถ้า..." — Python เช็คเงื่อนไข**จากบนลงล่าง** เจอข้อไหนจริงก่อน จะทำข้อนั้นแล้ว**จบ** (ไม่เช็คข้อถัดไป)
- **ลำดับสำคัญมาก!** ถ้าสลับ `>= 1000` ขึ้นก่อน `>= 2000` ยอด 2500 จะโดนดักที่ 5% ทันที ไม่ทันได้เช็ค 10%
- `discount * 100` → แปลง 0.10 ให้เป็น 10.0 (หน่วยเปอร์เซ็นต์)
- `total * (1 - discount)` → ยอดจ่ายจริงหลังหักส่วนลด

### 🔮 ทายก่อนรัน

ถ้าแก้ `total = 1500` — จะได้ส่วนลดกี่ % และจ่ายจริงเท่าไหร่?

### ✅ เฉลย

<details>
<summary>กดดูเฉลย</summary>

```
ได้ส่วนลด 5.0 %
จ่ายจริง 1425.0
```

1500 ผ่านเงื่อนไข `>= 1000` (แต่ไม่ถึง 2000) → ลด 5% → จ่าย 1500 − 75 = 1425

</details>

## 3. ทำงานซ้ำ: for + range()

โจทย์: บวกเลข 1 ถึง 5 ทีละรอบ แล้วดูผลสะสม

โค้ดอยู่ที่ไฟล์ `lesson2_loop.py`:

```python
total = 0
for i in range(1, 6):
    total = total + i
    print("รอบที่", i, "→ total =", total)
print("รวมทั้งหมด:", total)
```

**อธิบาย:**

- `range(1, 6)` → สร้างลำดับ `1, 2, 3, 4, 5` — **สังเกต! เลขท้าย (6) ไม่รวม** (range = "ตั้งแต่...ถึงก่อน...")
- `for i in ...:` — วนทีละค่า โดย `i` จะเปลี่ยนเป็นค่าของรอบปัจจุบัน
- บรรทัดที่**เยื้อง** = ทำงาน**ทุกรอบ**; บรรทัด `print` สุดท้ายที่**ไม่เยื้อง** = ทำงาน**ครั้งเดียว**หลังจบ loop
- `total = total + i` — ตัวแปรสะสม: เอาค่าเดิมบวกค่าใหม่ทับลงไปเรื่อยๆ
  (ทำไม `total = total + i` ถูกต้อง? เพราะ `=` ใน Python คือ "เอาค่าทางขวาใส่กล่องทางซ้าย" ไม่ใช่สมการคณิตศาสตร์)

### 🔮 ทายก่อนรัน

ค่า `total` สุดท้ายเท่ากับเท่าไหร่? และ loop วนทั้งหมดกี่รอบ? (ลองไล่ทีละรอบในหัวดู)

### ✅ เฉลย

<details>
<summary>กดดูเฉลย</summary>

```
รอบที่ 1 → total = 1
รอบที่ 2 → total = 3
รอบที่ 3 → total = 6
รอบที่ 4 → total = 10
รอบที่ 5 → total = 15
รวมทั้งหมด: 15
```

วน 5 รอบ (i = 1 ถึง 5) — สังเกตว่า total ถูกบวกเพิ่ม +1, +2, +3, +4, +5 ตามลำดับ
นี่คือท่าน "บวกสะสม" ที่จะใช้ตลอดทั้งสายงานข้อมูล 💪

</details>

## 4. จุดพลาดบ่อย (อ่านให้ดี!)

1. **ลืมโคลอน** — โค้ดแบบนี้รันไม่ขึ้น:
   ```python
   if score >= 80
       print("ผ่าน")
   ```
   จะได้ error `SyntaxError: expected ':'` → เติม `:` ท้ายบรรทัด `if` แค่นั้น
   (นิสัยติดตัวไว้: เจอ error ให้อ่าน **บรรทัดสุดท้าย** ของ error message — มันบอกสาเหตุเสมอ)

2. **Off-by-one กับ range** — `range(1, 5)` ได้ `1, 2, 3, 4` **ไม่รวม 5**
   ถ้าอยากได้ถึง 5 ต้องเขียน `range(1, 6)`

3. **สับสน `=` กับ `==`** — `if x = 5:` ผิด ต้องเป็น `if x == 5:`
   Python ใจดีจะแนะด้วยว่า `SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?`
   จำง่ายๆ: `=` คือสั่งใส่ค่า, `==` คือถามว่าเท่ากันไหม

4. **เยื้องไม่เท่ากัน** — บรรทัดที่อยู่ใน if ต้องเยื้องเท่ากันทุกบรรทัด ไม่งั้นเจอ `IndentationError`

5. **เทียบ int กับ str ตรงๆ** — ถ้า `amount` เป็น `"120"` (str) แล้วเขียน `if amount > 100:` จะเจอ
   `TypeError: '>' not supported between instances of 'str' and 'int'`
   → ต้องแปลงก่อน: `if int(amount) > 100:` (กับดักจากบทที่ 1 กลับมาแล้ว!)

## 5. แบบฝึกหัด

### ข้อ 1 — เติมโค้ดให้สมบูรณ์

```python
score = 480

# เติม: ถ้า score >= 500 ให้ print "เป้าใหญ่" ไม่งั้นให้ print "เป้าเล็ก"
```

### ข้อ 2 — แก้บั๊ก

รันไม่ขึ้น! หาสาเหตุจาก error message แล้วแก้ให้ผ่าน:

```python
score = 85

if score >= 80
    print("ผ่าน")
```

### ข้อ 3 — เขียนเองจากโจทย์

เขียนโค้ดหาผลรวมเลข **1 ถึง 10** (ใช้ `total` สะสมแบบตัวอย่างข้อ 3) แล้ว `print` ผลรวม**ครั้งเดียว**ตอนจบ

**ผลลัพธ์ที่คาดหวัง:** `55`

## 7. สรุปบทเรียน 📌

- `if / elif / else` = ให้โปรแกรมตัดสินใจ — เช็คจากบนลงล่าง ต้องมี `:` และเยื้องให้ถูก
- `for i in range(a, b):` = วนซ้ำตั้งแต่ `a` ถึง `b−1`
- `total = total + x` = ตัวแปรสะสม — ท่าไม้ตายของสายข้อมูล
- เทียบหรือคำนวณตัวเลขกับ `str` ตรงๆ ไม่ได้ ต้องแปลงก่อน

**บทต่อไป:** list กับ dict — กระเป๋าใส่ข้อมูลหลายๆ ชิ้น แล้วจะเริ่มเห็นภาพ "วิเคราะห์ข้อมูล" จริงๆ 🎒
