# บทเรียนที่ 1: ตัวแปรและชนิดข้อมูล

> **เป้าหมายบทนี้:** เข้าใจการเก็บค่าใส่ตัวแปร, รู้จักชนิดข้อมูล `int` / `str` / `float`, และใช้ `print()` กับ `type()` ได้
> ทุกโค้ดในบทนี้ **รันผ่านทดสอบมาแล้ว** — ลองรันเองเทียบดูได้เลย

---

## 1. ตัวแปร (variable) คืออะไร

ตัวแปรคือ "กล่องมีชื่อ" ไว้ใส่ค่า แล้วเรียกใช้ทีหลังผ่านชื่อกล่อง

```python
price = 120
name = "pen"
```

- `price = 120` → สร้างกล่องชื่อ `price` ใส่เลข 120
- `=` ใน Python **ไม่ใช่ "เท่ากับ"** แต่แปลว่า **"เอาค่าทางขวา ใส่กล่องทางซ้าย"**
- ตั้งชื่อกล่องเป็นอะไรก็ได้ (อังกฤษ, ห้ามเว้นวรรค) เช่น `total_price`, `user2`

---

## 2. ชนิดข้อมูล (data types) ที่ใช้บ่อย

| ชนิด | ชื่อเต็ม | ตัวอย่าง | ใช้กับ |
|---|---|---|---|
| `int` | integer — จำนวนเต็ม | `120`, `-5`, `0` | นับ, บวกลบเลขลงตัว |
| `float` | จำนวนทศนิยม | `3.5`, `0.25` | ราคา, ค่าเฉลี่ย, เปอร์เซ็นต์ |
| `str` | string — ข้อความ | `"pen"`, `"120"`, `"สวัสดี"` | ข้อความ, **ต้องมีเครื่องหมายคำพูดเสมอ** |
| `bool` | จริง/เท็จ | `True`, `False` | เงื่อนไข (บทที่ 2) |

⚠️ **จุดที่มือใหม่พลาดบ่อยสุด:** `120` กับ `"120"` ไม่เหมือนกัน!

- `120` = ตัวเลข (เอาไปคำนวณได้)
- `"120"` = ข้อความ (เอาไปคำนวณตรงๆ ไม่ได้)

---

## 3. ตัวอย่าง: ทดลองรัน

โค้ดอยู่ที่ไฟล์ `lesson1_basic.py`:

```python
price = 120
name = "pen"
total = price + 150

print(name, "ราคา", price)
print("ราคาหลังบวก:", total)
print(type(price), type(name))
```

**อธิบายทีละบรรทัด:**

- `price = 120` — กล่อง `price` ใส่ `int` 120
- `name = "pen"` — กล่อง `name` ใส่ `str` "pen"
- `total = price + 150` — บวก 120 + 150 = 270 เก็บลงกล่อง `total`
- `print(name, "ราคา", price)` — `print` รับได้**หลายค่า** คั่นด้วย comma แล้วพิมพ์ต่อกันโดยเว้นวรรคให้เอง
- `type(...)` — บอกชนิดข้อมูลของค่าที่ส่งเข้าไป

### 🔮 ทายก่อนรัน

1. บรรทัด `print(name, "ราคา", price)` จะแสดงอะไร?
2. `type(price)` กับ `type(name)` จะแสดงอะไร?

### ✅ เฉลย

<details>
<summary>กดดูเฉลย</summary>

```
pen ราคา 120
ราคาหลังบวก: 270
<class 'int'> <class 'str'>
```

**ข้อ 1:** `pen ราคา 120` — สังเกตว่ามี **3 ค่า** ที่ถูกพิมพ์: `name` ("pen") + ข้อความ "ราคา" + `price` (120) `print` จะเว้นวรรค 1 เคาะให้เองระหว่างค่า
**ข้อ 2:** `price` เป็น `<class 'int'>` (ตัวเลข) และ `name` เป็น `<class 'str'>` (ข้อความ)

</details>

## 4. กับดักสำคัญของสายข้อมูล: str vs int

```python
print("120" + "80")       # ได้ 12080 ← ต่อข้อความ ไม่ใช่บวกเลข!
print(int("120") + 80)    # ได้ 200   ← แปลงเป็นตัวเลขก่อน แล้วค่อยบวก
```

- `+` ระหว่าง `str` สองตัว = **เอาข้อความมาต่อกัน** (concatenate)
- `int("...")` = ฟังก์ชัน**แปลงข้อความให้เป็นจำนวนเต็ม**
- จำไว้: ข้อมูลจากไฟล์ CSV / ช่องกรอก ทุกอย่างเป็น `str` หมด → ก่อนบวกเลขต้องแปลงก่อนเสมอ
  (ย้อนไปดู: ในบทเรียนแรกเรื่อง `sales.csv` ค่า `amount` ก็เป็น `str` จริงๆ)

## 5. แบบฝึกหัด (ไล่จากง่ายไปยาก)

### ข้อ 1 — เติมโค้ดให้สมบูรณ์

```python
price1 = 120
price2 = 80
# เติมตรงนี้: print ยอดรวมในรูปแบบ "ยอดรวม: 200"
```

### ข้อ 2 — แก้บั๊ก

โค้ดนี้รันแล้ว error — หาสาเหตุและแก้ให้ถูก

```python
price = "120"
total = price + 150
print(total)
```

คำใบ้: error message คือ `TypeError: can only concatenate str (not "int") to str` — แปลว่ากำลังทำอะไรอยู่?

### ข้อ 3 — เขียนเองจากโจทย์

มีข้อความ `"3.5"` อยู่ในตัวแปร (เป็น str) อยากให้พิมพ์ผลลัพธ์หน้าจอแบบนี้:

```
3.5 บวก 1.5 ได้ 5.0
```

คำใบ้: ใช้ `float()` แปลงข้อความเป็นทศนิยม แล้วบวกด้วย `1.5`

## 6. เฉลยแบบฝึกหัด

price = int("120")

## 7. สรุปบทเรียน 📌

- ตัวแปร = กล่องมีชื่อ, `=` = เอาค่าทางขวาใส่กล่องทางซ้าย
- ชนิดข้อมูลหลัก: `int` (เต็ม), `float` (ทศนิยม), `str` (ข้อความ — ต้องมี quotes)
- `120` ≠ `"120"` และข้อมูลจากไฟล์มักเป็น `str` → ต้องแปลงด้วย `int()` / `float()`
- `type(x)` ใช้เช็คชนิดข้อมูลได้
- `print()` ใส่หลายค่าได้ พิมพ์ต่อกันโดยเว้นวรรคให้เอง

**บทต่อไป:** เงื่อนไข (if) — ให้โปรแกรม "ตัดสินใจ" ได้ เช่น ถ้ายอดขายเกินเป้าให้พิมพ์ว่าผ่าน 🎯
