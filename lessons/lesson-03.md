# บทเรียนที่ 3: list กับ dict (เก็บข้อมูลหลายชิ้น)

> **เป้าหมายบทนี้:** เก็บข้อมูลหลายรายการในตัวแปรเดียวด้วย list และเก็บข้อมูลเป็นคู่ key–value ด้วย dict — สองตัวนี้คือหัวใจของงานข้อมูล
> โค้ดทุกตัวอย่างในบทนี้ **รันผ่านทดสอบมาแล้ว**

## 1. list — กล่องหลายช่อง

โจทย์: เก็บราคาสินค้าหลายชิ้นไว้ด้วยกัน

โค้ดอยู่ที่ไฟล์ `lesson3_list.py`:

```python
prices = [120, 80, 200, 150]

print(prices[0])
print(len(prices))
print(prices[1] + prices[3])

prices.append(90)
print(prices)
print(sum(prices))
```

**อธิบายทีละส่วน:**

- `[120, 80, 200, 150]` — list เขียนด้วยวงเล็บเหลี่ยม `[ ]` คั่นสมาชิกด้วย comma
- `prices[0]` — ดึงช่องหมายเลข 0 → ได้ 120
  ⚠️ **นับจาก 0!** ช่องแรก = index 0, ช่องที่สอง = index 1, ... ช่องสุดท้าย = index `len-1`
- `len(prices)` — นับจำนวนสมาชิก → 4
- `prices.append(90)` — **เพิ่ม** 90 เข้าท้าย list (จาก 4 ตัว กลายเป็น 5 ตัว)
- `sum(prices)` — บวกทุกตัวใน list ให้อัตโนมัติ

### 🔮 ทายก่อนรัน

1. `prices[0]` กับ `prices[1]` ได้ค่าอะไร?
2. หลัง `append(90)` แล้ว `sum(prices)` ได้เท่าไหร่? (อย่าลืม 90 ที่เพิ่งเพิ่มเข้าไป!)

### ✅ เฉลย

<details>
<summary>กดดูเฉลย</summary>

```
120
4
230
[120, 80, 200, 150, 90]
640
```

- `prices[0]` = 120, `prices[1]` = 80
- `prices[1] + prices[3]` = 80 + 150 = 230
- หลัง append: sum = 120 + 80 + 200 + 150 + 90 = **640**

</details>

## 2. วน list ด้วย for

โจทย์: หาผลรวมและค่าเฉลี่ยของราคาทั้งหมด

โค้ดอยู่ที่ไฟล์ `lesson3_loop.py`:

```python
prices = [120, 80, 200, 150, 90]

total = 0
for p in prices:
    total = total + p

print("รวม", total)
print("เฉลี่ย", total / len(prices))
```

**อธิบาย:**

- `for p in prices:` — วนหยิบสมาชิกทีละตัวจาก list มาใส่ `p` (ไม่ต้องใช้ `range` เลย — วนของจริงได้โดยตรง)
- `total = total + p` — บวกสะสมแบบบทที่ 2
- `total / len(prices)` — เครื่องหมาย `/` คือหาร (ได้ผลเป็นทศนิยม float)
- นี่คือโครง "สรุปข้อมูล" พื้นฐานสุด: **รวม** แล้ว **เฉลี่ย**

### 🔮 ทายก่อนรัน

รันแล้ว 2 บรรทัดสุดท้ายได้อะไร?

### ✅ เฉลย

<details>
<summary>กดดูเฉลย</summary>

```
รวม 640
เฉลี่ย 128.0
```

รวม = 640 (5 ตัวรวม 90 แล้ว) → เฉลี่ย = 640 / 5 = **128.0**

</details>

## 3. dict — กล่องติดป้าย (key: value)

โจทย์: เก็บข้อมูลสินค้า 1 รายการ แบบมีป้ายกำกับ

โค้ดอยู่ที่ไฟล์ `lesson3_dict.py`:

```python
row = {"product": "pen", "amount": 120}

print(row["product"])
row["amount"] = row["amount"] + 30
print(row)
print(row.get("color", "ไม่มีข้อมูล"))
```

**อธิบาย:**

- dict เขียนด้วยปีกกา `{ }` เก็บเป็นคู่ `"ป้าย": ค่า` (key: value)
- `row["product"]` — เปิดช่องตาม**ป้าย** (ต่างจาก list ที่เปิดตาม**เลข** index)
- `row["amount"] = ...` — แก้ค่าในช่องได้ทันที (dict เพิ่มช่องใหม่ก็ใช้วิธีเดียวกัน)
- `row.get("color", "ไม่มีข้อมูล")` — เปิดช่องแบบ**ปลอดภัย**: ถ้าป้าย `"color"` ไม่มีอยู่ ให้คืนค่าที่เรากำหนดแทนที่จะพัง
  ⭐ ท่านี้สำคัญมาก — จะได้ใช้เต็มๆ ในบทที่ 5
- 💡 มองภาพ: **CSV 1 แถว = 1 dict** ที่มีป้าย "date", "product", "amount" (บทที่ 5 จะเห็นเต็มๆ)

### 🔮 ทายก่อนรัน

3 บรรทัดสุดท้าย print อะไรออกมาบ้าง?

### ✅ เฉลย

<details>
<summary>กดดูเฉลย</summary>

```
pen
{'product': 'pen', 'amount': 150}
ไม่มีข้อมูล
```

- `row["amount"]` เดิม 120 → +30 → 150 แล้ว print ทั้ง dict
- `"color"` ไม่มีใน dict → `.get()` คืนค่า default `"ไม่มีข้อมูล"`

</details>

## 4. จุดพลาดบ่อย

1. **index เริ่มที่ 0** — ช่องแรกคือ `[0]` ไม่ใช่ `[1]` — ถ้าเปิดเกินขอบเขตจะเจอ
   `IndexError: list index out of range` (เช่น list มี 3 ตัว แต่เขียน `prices[3]`)
2. **เปิด dict ด้วยป้ายที่ไม่มี** → `KeyError: 'price'` — ทางแก้: ใช้ `.get("price", ค่าเริ่มต้น)` แทน `["price"]`
3. **เทียบให้ออกว่าควรใช้ list หรือ dict:**
   - list = ของหลายชิ้นเรียงกัน เปิดด้วย**ตัวเลข** (เหมาะกับ "รายการ" เช่น ราคาสินค้าทั้งหมด)
   - dict = สิ่งเดียวแต่มี**หลายคุณสมบัติ** เปิดด้วย**ป้าย** (เหมาะกับ "หนึ่งแถวข้อมูล" เช่น สินค้าหนึ่งชิ้นมียี่ห้อ/ราคา/จำนวน)

## 5. แบบฝึกหัด

### ข้อ 1 — เติมโค้ดให้สมบูรณ์

```python
products = ["pen", "book", "bag"]
# เติม: print ชื่อสินค้าชิ้นแรก และ print จำนวนสินค้าทั้งหมด
```

### ข้อ 2 — แก้บั๊ก

โค้ดนี้รันแล้วพัง — หาสาเหตุและแก้ให้ปลอดภัย (ถ้าไม่มีข้อมูลให้ได้เลข 0):

```python
row = {"product": "pen", "amount": 120}
print(row["price"])
```

### ข้อ 3 — เขียนเองจากโจทย์

มีข้อมูลหลายแถวแบบเดียวกับที่ CSV จะให้มา จงเขียนโค้ดสรุป**ยอดขายรวมต่อสินค้า**:

```python
rows = [
    {"product": "pen",  "amount": 120},
    {"product": "book", "amount": 350},
    {"product": "pen",  "amount": 80},
]

# เขียนต่อ: วน rows รวมยอดต่อสินค้า แล้ว print totals
```

**ผลลัพธ์ที่คาดหวัง:** `{'pen': 200, 'book': 350}`

> 🔥 ข้อนี้คือ "เครื่องยนต์" ตัวเดียวกับที่ใช้ในบทสุดท้าย — ทำได้แล้วไปได้ไกลแน่นอน

## 6. เฉลยแบบฝึกหัด

<details>
<summary>กดดูเฉลย</summary>

**ข้อ 1:**

```python
products = ["pen", "book", "bag"]
print(products[0])     # pen
print(len(products))   # 3
```

**ข้อ 2:** ใช้ `.get()` เปิดช่องแบบปลอดภัย

```python
row = {"product": "pen", "amount": 120}
print(row.get("price", 0))   # 0
```

(ถ้าใช้ `row["price"]` จะได้ `KeyError: 'price'` — เพราะป้าย "price" ไม่มีใน dict)

**ข้อ 3:**

```python
totals = {}
for row in rows:
    product = row["product"]
    totals[product] = totals.get(product, 0) + row["amount"]

print(totals)   # {'pen': 200, 'book': 350}
```

สำนวน `totals[product] = totals.get(product, 0) + row["amount"]` อ่านว่า:
"ยอดเดิมของสินค้านี้ (ถ้ายังไม่เคยมี = 0) บวกยอดใหม่ แล้วเก็บทับลงไป" — **ท่าไม้ตายที่ต้องจำให้ขึ้นใจ!**

</details>

## 7. สรุปบทเรียน 📌

- `list` = `[...]` เปิดช่องด้วย index (**เริ่ม 0**), เพิ่มด้วย `.append()`, นับด้วย `len()`, รวมด้วย `sum()`
- `dict` = `{key: value}` เปิดช่องด้วยป้าย — ใช้ `.get(ป้าย, ค่าเริ่มต้น)` ปลอดภัยกว่า `[...]` เสมอ
- `for x in ...` วนได้ทั้ง list และ dict แบบนับอัตโนมัติ
- ท่า `totals[k] = totals.get(k, 0) + v` = หัวใจของการสรุปยอดทุกชนิด

**บทต่อไป:** ห่อโค้ดทั้งหมดเป็น "ฟังก์ชัน" 📦 — เขียนครั้งเดียว เรียกใช้ได้ตลอดไป
