# บทเรียนที่ 4: ฟังก์ชัน (function)

> **เป้าหมายบทนี้:** ห่อโค้ดเป็นก้อน reusable — มีชื่อ มีทางเข้า (parameter) มีทางออก (return)
> โค้ดทุกตัวอย่างในบทนี้ **รันผ่านทดสอบมาแล้ว**

## 1. ประกาศและเรียกใช้ฟังก์ชัน

โจทย์: ทักทายคนหลายคน โดยไม่ต้องเขียนโค้ดซ้ำ

โค้ดอยู่ที่ไฟล์ `lesson4_greet.py`:

```python
def greet(name):
    print("สวัสดี", name)

greet("นัท")
greet("มะลิ")
```

**อธิบายทีละส่วน:**

- `def greet(name):` — **ประกาศ**ฟังก์ชันชื่อ `greet` รับข้อมูลเข้าหนึ่งชิ้น (`name` เรียกว่า **parameter** = ช่องรับของ)
- โค้ดในฟังก์ชันต้อง**เยื้อง** (เหมือน if/for)
- `greet("นัท")` — **เรียกใช้** ฟังก์ชัน โดยส่ง `"นัท"` เข้าไปเป็น `name` ของรอบนั้น
- ⚠️ แค่เขียน `def` โค้ดข้างใน**ยังไม่ทำงาน** — ต้อง**เรียก**ด้วยชื่อ + `()` จนกว่านั้น

### 🔮 ทายก่อนรัน

1. รันแล้วได้อะไร?
2. ถ้าลบบรรทัด `greet("นัท")` ออก (CB) จะเหลืออะไร?

### ✅ เฉลย

<details>
<summary>กดดูเฉลย</summary>

```
สวัสดี นัท
สวัสดี มะลิ
```

ถ้าลบบรรทัด `greet("นัท")` ออก จะเหลือแค่ `สวัสดี มะลิ`
(โค้ดในฟังก์ชันทำงาน "ต่อเมื่อถูกเรียก" เท่านั้น — เรียกกี่ครั้งก็ทำงานกี่รอบ)

</details>

## 2. return — ส่งค่ากลับออกมาใช้ต่อ

โจทย์: อยากเอาผลบวกจากฟังก์ชันไปคำนวณต่อ

โค้ดอยู่ที่ไฟล์ `lesson4_return.py`:

```python
def add(a, b):
    return a + b

result = add(3, 4)
print(result)
print(result + 10)
```

**อธิบาย:**

- `return` = **ส่งค่ากลับ** ออกมาจากฟังก์ชัน ให้เอาไปใช้ต่อได้ (เก็บใส่ตัวแปร / บวกเพิ่ม / ส่งต่อให้ฟังก์ชันอื่น)
- **ต่างจาก `print` แบบสำคัญ:** `print` แค่แสดงผลบนจอแล้วค่าจบ — `return` ส่งค่าออกมา**ให้โค้ดที่เรียกได้ใช้จริง**
- เวลาเรียกฟังก์ชันที่มี `return` — ทั้งก้อน `add(3, 4)` จะกลายเป็นค่าที่คืนมา (ตรงนี้ = 7)

### 🔮 ทายก่อนรัน

`print` 2 บรรทัดสุดท้ายได้อะไรบ้าง?

### ✅ เฉลย

<details>
<summary>กดดูเฉลย</summary>

```
7
17
```

`add(3, 4)` คืน 7 → `result = 7` → พิมพ์ 7 และ `7 + 10` = 17

</details>

## 3. รวมทุกอย่าง: ฟังก์ชัน + if

โจทย์: ฟังก์ชันคิดยอดจ่ายหลังหักส่วนลด (ทบทวนบทที่ 2 ในรูปแบบฟังก์ชัน)

โค้ดอยู่ที่ไฟล์ `lesson4_discount.py`:

```python
def apply_discount(total):
    if total >= 2000:
        return total * 0.90
    return total

print(apply_discount(2500))
print(apply_discount(500))
```

**อธิบาย:**

- ในฟังก์ชันใช้ `if` และ `return` ได้ตามใจ
- พอ `return` ทำงาน ฟังก์ชันจะ**จบทันที** (บรรทัดถัดไปไม่ทำงาน)
  - ยอด 2500 → เข้าเงื่อนไข → `return 2250.0` แล้วจบเลย
  - ยอด 500 → ไม่เข้าเงื่อนไข → ไหลลงมาถึง `return total` (คืนราคาเต็ม)

### 🔮 ทายก่อนรัน

2 บรรทัดสุดท้ายได้อะไร? (2500 → ? / 500 → ?)

### ✅ เฉลย

<details>
<summary>กดดูเฉลย</summary>

```
2250.0
500
```

2500 × 0.90 = 2250.0 (หัก 10%) — ส่วน 500 ไม่ถึง 2000 จึงคืน 500 เต็ม

</details>

## 4. จุดพลาดบ่อย

1. **ใช้ `print` แทน `return` (พลาดบ่อยสุดในสายนี้!)** — ดูตัวอย่างนี้:
   ```python
   def double(x):
       print(x * 2)

   result = double(5)
   print(result + 1)
   ```
   จะได้ `10` แล้ว**พัง**ด้วย `TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'`
   เพราะ `print` ไม่ได้ส่งค่ากลับ → `result` กลายเป็น `None` → `None + 1` จึงพัง
   **แก้:** ใช้ `return x * 2` แทน `print`
2. **ลืมวงเล็บตอนเรียก** — `greet` เฉยๆ คือ "ตัวฟังก์ชันเอง" ไม่ใช่ "ผลลัพธ์" — ต้อง `greet("นัท")`
3. **ตัวแปรในฟังก์ชัน ข้างนอกมองไม่เห็น** — ตัวแปรที่สร้างในฟังก์ชัน (เช่น `discount`) ใช้ได้แค่ในฟังก์ชันนั้น (ค่อยๆ จำ ไว้เจอตอนยาวๆ)
4. **ตั้งชื่อให้สื่อความหมาย** — `calculate_discount` อ่านแล้วเข้าใจ ดีกว่า `calc()` หรือ `d()` — อีกเดือนกลับมาอ่านยังเข้าใจ

## 6. เฉลยแบบฝึกหัด

<details>
<summary>กดดูเฉลย</summary>

**ข้อ 1:**

```python
def average(numbers):
    return sum(numbers) / len(numbers)

print(average([70, 80, 90]))   # 80.0
```

**ข้อ 2:** เปลี่ยน `print` เป็น `return`

```python
def double(x):
    return x * 2

result = double(5)
print(result + 1)   # 11
```

(สาเหตุ: `print` แสดงผลแต่ไม่ส่งค่ากลับ — `result` จึงเป็น `None` แล้ว `None + 1` พัง)

**ข้อ 3:**

```python
def describe(price):
    if price >= 1000:
        return "แพง"
    return "ถูก"

prices = [120, 2500, 999]
for price in prices:
    print(describe(price))
```

</details>

## 7. สรุปบทเรียน 📌

- `def ชื่อ(ทางเข้า):` ประกาศฟังก์ชัน — เรียกด้วย `ชื่อ(ค่า)`; parameter = ช่องรับของ
- `return` = ส่งค่ากลับ**เอาไปใช้ต่อ** — `print` = แค่โชว์บนจอ
- `return` ทำให้ฟังก์ชัน**จบทันที** — ใช้ร่วมกับ `if` ได้สวยงาม
- เขียนครั้งเดียว เรียกใช้ได้ตลอด → โค้ดสั้นลง ตรวจง่ายขึ้น
